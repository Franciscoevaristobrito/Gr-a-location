# Bitácora

Memoria de corto plazo. Una entrada por **semana** (no por día — sería demasiado).

## Para qué sirve

- Saber qué hiciste y aprendiste cada semana.
- Material para retrospectivas: ¿avanzo o me estanco?
- Si una idea no merece todavía un archivo en `decisiones/`, vive aquí.

## Convención

Un archivo por semana: `YYYY-Wnn.md` (semana ISO).

Ejemplo: la semana del 18-24 de mayo 2026 → `2026-W21.md`.

## Plantilla

```markdown
# Semana 2026-W21 (18-24 mayo)

## Lo que se hizo
- ...
- ...

## Lo que se aprendió
- ...

## Decisiones tomadas
- Decidimos X (→ ver `decisiones/00NN-...`)

## Pendientes para la próxima semana
- [ ] ...
- [ ] ...

## Bugs/preguntas abiertas
- ...
```

## Cuándo se llena

Viernes en la tarde, junto con la foto del pizarrón.
**10 minutos máximo.** No es un diario íntimo, son notas operacionales.
