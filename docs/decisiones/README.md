# Decisiones

Una decisión = un archivo. Numeradas en orden cronológico.

## Para qué sirve

Cuando dentro de 2 meses te preguntes *"¿por qué hicimos esto así?"*, aquí está la respuesta.

## Plantilla

Crea un archivo con el formato `NNNN-titulo-corto.md` y usa esta estructura:

```markdown
# NNNN — Título corto

**Fecha:** YYYY-MM-DD
**Estado:** Aceptada / Reemplazada / Pendiente

## Contexto
¿Qué problema estábamos resolviendo?

## Decisión
¿Qué decidimos hacer?

## Alternativas consideradas
- Opción A — por qué no
- Opción B — por qué no

## Consecuencias
- Lo bueno
- Lo malo / lo que aceptamos a cambio
```
