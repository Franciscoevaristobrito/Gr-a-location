# Fotos del pizarrón

Snapshot semanal del pizarrón antes de borrarlo.

## Para qué sirve

A los 3 meses te vas a preguntar *"¿en qué estaba pensando en mayo?"*. Una foto vale por mil notas.

## Ritual recomendado

**Cada viernes al cerrar la semana:**

1. Foto del pizarrón completo con el celular.
2. Renombrar a `YYYY-MM-DD.jpg` (fecha del viernes).
3. Subir a esta carpeta.
4. (Opcional) Crear un archivo `YYYY-MM-DD-notas.md` con 2-3 líneas: qué se cerró, qué quedó pendiente.

## Convención de nombre

```text
2026-05-23.jpg            ← foto principal
2026-05-23-notas.md       ← notas opcionales
2026-05-23-detalle.jpg    ← si una zona necesita zoom
```
